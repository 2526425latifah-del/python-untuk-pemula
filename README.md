# Praktikum Python untuk Pemula

Repositori tugas Praktikum Python untuk Pemula (Santrikoding) oleh Latifah Ulumiah, SMKN 2 Subang.

## Isi

- Bab 1: hello.py, versi_python.py
- Bab 2: variable_numbers.py, variable_string.py, variable_boolean.py
- Bab 3: operator_aritmatika.py, operator_comparison.py, operator_logical.py
- Bab 4: condition_if.py, condition_if_elif.py, condition_if_else.py
- Bab 5: loop_for_1.py, loop_for_2.py, loop_while.py, loop_for_break.py, loop_for_continue.py
- Bab 6: lists_*.py dan dictionaries_*.py
- Bab 7: function_*.py
- Bab 8: class_*.py
- Bab 9: pip_camelcase.py, info_venv.py
- Bab 10: KONFIGURASI_IDE.md, .vscode/settings.json
- Bab 11: README.md, requirements.txt

Bukti hasil eksekusi ada di folder screenshots/.

## Cara menjalankan

1. python -m venv venv
2. source venv/bin/activate
3. pip install -r requirements.txt
4. python hello.py

## Catatan

Kode mengikuti contoh pada modul Santrikoding, sedangkan data dan contohnya disesuaikan sendiri. Pengerjaan dilakukan di WSL2 Arch Linux (bukan PyCharm seperti di modul) dengan virtual environment bernama venv.
